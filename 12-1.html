12-1 CSS 变量演示

使用 :root 定义全局变量，通过 var() 引用，实现一键换肤与动态调整

交互式变量面板

-var
var(--qyy-primary) color: var(--qyy-primary)
var
var(--qyy-radius) border-radius: var(--qyy-radius)
var
var(--qyy-shadow) box-shadow: var(--qyy-shadow)
var
var(--qyy-font-size) font-size: var(--qyy-font-size)
/* 在 :root 中定义变量 */
:root {
  --qyy-primary: #2563eb;
  --qyy-radius: 16px;
  --qyy-font-size: 1rem;
}

/* 在任何选择器中引用变量 */
.qyy_box {
  background: var(--qyy-primary);
  border-radius: var(--qyy-radius);
}
