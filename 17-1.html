JSON 数据格式

JavaScript Object Notation · 齐英伊 24001010829

1JSON 是什么 一种轻量级的数据交换格式

{ } 对象

用花括号包裹，存放「键 : 值」对。键必须用双引号。

[ ] 数组

用方括号包裹，存放有序的值列表，值之间用逗号分隔。

嵌套

对象里可以放数组，数组里可以放对象，层层嵌套表示复杂结构。

2一段完整的 JSON 学生信息
{ "name": "齐英伊", "id": "24001010829", "age": 20, "isStudent": true, "graduated": null, "courses": [ "高级网页设计", "JavaScript 基础" ], "address": { "city": "成都", "zip": "610000" } }
3六条语法规则
✓

键名必须用双引号包裹，不能用单引号，也不能不加引号。

✓

值只能是六种类型：字符串、数字、布尔、null、对象、数组。

✗

不允许注释：// 说明和/* 说明 */都会让解析报错。

✗

最后一个成员后面不能有逗号，"a":1,} 是非法写法。

✗

不允许出现 undefined、function、NaN 这些 JS 独有的值。

✓

字符串里的双引号要用反斜杠转义："say \"hi\""。

4JSON 与 JavaScript 对象的区别
JSON（文本格式）
{ "name": "齐英伊", "age": 20 }
JS 对象（代码）
{ name: '齐英伊', age: 20 }
// 字符串 → 对象：解析 const qyy_obj = JSON.parse('{"name":"齐英伊","age":20}'); // 对象 → 字符串：序列化 const qyy_str = JSON.stringify(qyy_obj);
