一、滚动进度 ↔ 三阶段映射

滚动区间 阶段 驱动的 3D 效果
0 → 35% 3D 镜头平移 世界层 translateX / translateZ / rotateX·Y：镜头从左后方推近并环绕归正，地面网格同步视差
20% → 55% 模型出场 立方体自下方升起（translateY 170px→0）、放大（scale 0.35→1）、6 面同时淡入
60% → 100% 形变 6 面沿 Z 轴分解散开并淡出，前脸推近放大成圆角铭牌（translateZ 45→130px、scale 1→2.15、发光阴影）

二、实现要点

position: sticky 固定视口

外层轨道高 400vh，内层视口 sticky; top:0 钉在屏幕上；滚动经过轨道时产生 0→1 的天然进度。

JS 计算进度写入 CSS 变量

scrollTop / (轨道高 - 视口高) 得到 --qyy-p，再拆出 --qyy-cam / --qyy-in / --qyy-morph 三个阶段变量，CSS 只负责 calc() 插值。

镜头 = 世界层反向变换

模型不动，滚动时对 .qyy_world 做 translateX·Z + rotateX·Y，配合 perspective 即等价于镜头平移环绕。

变换与动画分层

悬浮呼吸动画放在 .qyy_float 独立层，滚动变换写在 .qyy_model / .qyy_world，互不覆盖 transform。

形变 = translateZ + scale + opacity

立方体各面 translateZ 拉大形成分解视图，非前脸 opacity→0，前脸 scale 放大成铭牌，全程只动合成层属性。

纯原生，无依赖

无框架无 CDN：原生 scroll 事件（passive）+ CSS 自定义属性 + calc()。也可以用 CSS animation-timeline: scroll()，但需较新 Chromium。

提示：滚动驱动动画的关键是把「一个连续进度」拆成若干阶段变量分别插值，比在一个 @keyframes 里堆关键帧更易调；只改 transform / opacity 不触发重排，400vh 长轨道滚动依然流畅。滚动到不同位置可反复观察三阶段衔接。
