Web 前端的长度单位

齐英伊 · 学号 829 · 绝对单位与相对单位对照演示

一、常见长度单位速查表

单位 类型 说明
px绝对单位像素，最常用，1px ≈ 1/96 英寸
in绝对单位英寸，1in = 96px
cm绝对单位厘米，1cm ≈ 37.8px
mm绝对单位毫米，1mm ≈ 3.78px
pt绝对单位磅（打印单位），1pt = 4/3 px
pc绝对单位派卡，1pc = 12pt = 16px
%相对单位相对父元素同属性的百分比
em相对单位相对【当前元素】父级的 font-size
rem相对单位相对根元素 html 的 font-size，推荐
vw视口单位相对视口宽度，1vw = 视口宽的 1%
vh视口单位相对视口高度，1vh = 视口高的 1%
ch相对单位相对当前字体数字 0 的宽度
ex相对单位相对当前字体 x 的高度（x-height）

二、绝对单位演示

px 像素

屏幕上的固定点数，不随父元素或窗口变化。

width: 100px
width: 200px
width: 300px

cm / mm / in / pt

来自印刷业的绝对单位，网页中较少使用，1in 恒等于 96px。

width: 1cm ≈ 37.8px
width: 1in = 96px
width: 72pt = 96px

三、相对单位演示

% 百分比

相对父元素的宽度（宽度属性）或 font-size（字号属性）。

父元素 width: 100%
子元素 width: 60%

em 相对父元素

父元素 font-size: 20px，子元素 1.5em = 30px；层层嵌套会倍乘。

父级 20px
1.5em = 30px

rem 相对根元素

只看 html 的 font-size（默认 16px），2rem = 32px，不受父级影响。

父级 12px（不影响 rem）
2rem = 32px

ch / ex 字符相关

随字体变化：ch 是数字 0 的宽，ex 是小写 x 的高。

width: 10ch
width: 30ex

四、视口单位演示（vw / vh）

相对浏览器可视区域

随窗口缩放实时变化，常用于响应式大屏排版；下方方块高度为 12vh，宽度各占剩余空间。

height: 12vh
视口高的 12%
width: 约 50% 容器
height: 12vh
提示：实际开发中优先使用 rem（配合根字号做整体缩放）与 % / vw / vh（做自适应布局）； px 适合边框、阴影等不需要缩放的细节。em 适合局部成比例缩放，但要注意嵌套倍乘。
